### (b) Урвуу эрэмбэлэгдсэн оролтод n(n − 1)/2

Лекцийн шинжилгээнд i-р давталтад (i = 2, …, n) while нөхцөл tᵢ удаа шалгагдаж,
давталтын бие (зөөх мөр) tᵢ − 1 удаа биелэгдэнэ гэж тэмдэглэсэн.

Оролт хатуу буурах үед i-р алхмын эхэнд A[1..i − 1] нь анхны эхний i − 1 гишүүн бөгөөд
бүгд key = A[i]-ээс их. Иймд while давталт j = i − 1-ээс j = 0 хүртэл зогсолтгүй явж,
A[1..i − 1]-ийн бүх гишүүнийг зөөнө: tᵢ = i, зөөлт tᵢ − 1 = i − 1. Нийт зөөлт:

$$
\sum_{i=2}^{n}(t_i - 1) = \sum_{i=2}^{n} i - \sum_{i=2}^{n} 1
= \left(\frac{n(n+1)}{2} - 1\right) - (n - 1) = \frac{n(n-1)}{2}.
$$

Шалгалт: H5 (n = 8) → 28 = 8·7/2; `test_reverse_sorted_is_n_choose_2` (n = 4, 8, 16, 64);
n = 10⁴ үед 49 995 000 = 10⁴·9999/2 (4-р даалгаврын хүснэгт).

### (c) n(n − 1)/2 = Θ(n²)

Тодорхойлолт: f(n) = Θ(g(n)) ⇔ бүх n ≥ n₀ үед 0 ≤ c₁g(n) ≤ f(n) ≤ c₂g(n) байх c₁, c₂, n₀ > 0
тогтмол оршино. f(n) = n(n − 1)/2 = n²/2 − n/2.

- **Дээд хязгаар.** n ≥ 1 үед n/2 ≥ 0 тул n²/2 − n/2 ≤ n²/2. ⇒ c₂ = 1/2.
- **Доод хязгаар.** n²/2 − n/2 ≥ c₁n² ⇔ 1/2 − 1/(2n) ≥ c₁. Зүүн тал n-ээр өсдөг тул n ≥ 2
  үед 1/2 − 1/4 = 1/4 ≥ c₁. ⇒ c₁ = 1/4.

Иймд c₁ = 1/4, c₂ = 1/2, n₀ = 2 үед бүх n ≥ 2-т n²/4 ≤ n(n − 1)/2 ≤ n²/2 тул
n(n − 1)/2 = Θ(n²). (n = 2 үед 1 ≤ 1 ≤ 2 ✓)

### (b) n = 2ᵏ үед яг n·k

Merge(A, p, q, r) нь L, R-ийн гишүүн бүрийг A уруу яг нэг удаа буцааж бичдэг тул
бичилтийн тоо нь n_L + n_R = r − p + 1 буюу нэгтгэж буй хэсгийн урт. Энэ нь оролтын
агуулгаас хамаарахгүй (W4, W5, W14, W15 бүгд 24).

Лекцийн T(n) = 2T(n/2) + cn давталтын модтой ижил мод зурна, зөвхөн зангилааны өртөг нь
cn-ийн оронд «бичилтийн тоо»:

```text
түвшин                                         бичилт
  0                    n                         n
                    /     \
  1              n/2       n/2                   2 · n/2 = n
                /   \     /   \
  2           n/4  n/4  n/4  n/4                 4 · n/4 = n
              ...                                ...
  k−1     2  2  2  ...  2  2  2   (2^(k−1) ш)     2^(k−1) · 2 = n
  k       1 1 1 1  ...  1 1 1 1   (2^k ш)        0  (навч — Merge дуудагдахгүй)
```

j-р түвшинд (j = 0, …, k − 1) n/2ʲ урттай 2ʲ зангилаа байх бөгөөд түвшин бүрийн нийт
бичилт 2ʲ · n/2ʲ = n. Merge хийгддэг түвшин k = lg n ширхэг, навчны түвшинд бичилт 0.
Нийт: n · k = n lg n.

Хугацааны шинжилгээнд навч бүр Θ(1) өртөгтэй тул lg n + 1 түвшин гарч байсан бол энд
навч бичилт хийхгүй тул яг n·k гарч байна. Шалгалт: `test_power_of_two_is_n_lg_n`
(k = 1..10), W4/W5 (n = 8, k = 3) → 24.

## 3. Хоёртын хайлт

`binary_search` нь Recursive-Binary-Search-ийг 0-ээс эхэлсэн товъёгоор (p = 0, r = n − 1)
хөрвүүлсэн бөгөөд олдсон товъёг (олдохгүй бол −1) болон эхний дуудалтыг оролцуулсан нийт
дуудалтын тоог буцаана.

### (a)

`binary_search_01.tsv`-ийн 12 мөр (товъёг, дуудалтын тоо, ⌊lg n⌋ + 2 хязгаар) хоёр хэл
дээр давсан.

### (b) Дахин дуудах тэгшитгэл ба давталтын мод

m = r − p + 1 урттай хэсэгт q = ⌊(p + r)/2⌋ гэвэл зүүн хэсэг A[p..q − 1]-ийн урт
⌊(m − 1)/2⌋, баруун хэсэг A[q + 1..r]-ийн урт ⌊m/2⌋. Дуудалт бүр Θ(1) ажил хийж, хамгийн
ихдээ нэг дэд бодлого руу ордог. Муу тохиолдолд (их хэсэг рүү явбал):

$$
T(n) = T(\lfloor n/2 \rfloor) + \Theta(1), \qquad T(0) = \Theta(1).
$$

Нэгтгэн эрэмбэлэлтийн модоос ялгаатай нь зангилаа бүр ганц хүүхэдтэй тул мод нь гинж
болно:

```text
дуудалт   хэсгийн урт           өртөг
  1          n                    c
  │
  2          ⌊n/2⌋                c
  │
  3          ⌊n/4⌋                c
  │          ...
  ⌊lg n⌋+1   ⌊n/2^⌊lg n⌋⌋ = 1     c      ← A[q] ≠ x
  │
  ⌊lg n⌋+2   0  (p > r)           c      ← NIL
```

⌊⌊n/2ʲ⌋/2⌋ = ⌊n/2ʲ⁺¹⌋ тул j-р түвшний урт ⌊n/2ʲ⌋. Энэ нь ⌊n/2ʲ⌋ ≥ 1 ⇔ 2ʲ ≤ n ⇔
j ≤ ⌊lg n⌋ үед хоосон биш. Иймд урт ≥ 1 түвшин ⌊lg n⌋ + 1 ширхэг, түүний дараа p > r
болсон нэг дуудалт байна. Нийт дуудалт **⌊lg n⌋ + 2**, хугацаа c(⌊lg n⌋ + 2) = Θ(lg n).

Энэ муу тохиолдол x нь бүх гишүүнээс их үед (үргэлж баруун тийш) яг гарна:
B6 (n = 8, x = 99) → 5 = 3 + 2, B12 (n = 100, x = 197) → 8 = 6 + 2. Зүүн тийш явахад
хэсэг ⌊(m − 1)/2⌋ болж илүү хурдан багасдаг тул B5 (x = 0) → 4 дуудалт. Хамгийн сайн
тохиолдолд эхний дунд цэгт олдоно (B3 → 1 дуудалт).

### (d) Дахин дуудах тэгшитгэл

Урьдчилсан алхам (pos, C үүсгэх) Θ(n). `sort_and_count` нь хоёр хагаст дахин дуудагдаж,
шугаман хугацааны Merge хийнэ:

$$

$$

Энэ нь нэгтгэн эрэмбэлэлтийн тэгшитгэлтэй ижил. Давталтын модонд lg n + 1 түвшин, түвшин

Θ(n) + Θ(n lg n) = **Θ(n lg n)**.
