**Аргачлал.** Эхлээд лабын 1-р даалгаврын зөөх эрэмбэлэлтийг шууд илгээв. Энэ нь
муу тохиолдолд Θ(n²) тул n ≤ 5·10⁴ хязгаарт багтахгүй. LeetCode-ийн шалгагч хоёр
талаас нь татгалзсан:

  prohibited quadratic sorting algorithm» гэж O(n lg n) шаардлагыг зөрчсөнийг илрүүлсэн.
- Гүйцэтгэлд эхний 10 жижиг тест давж, 11-р тест (≈5·10⁴ элемент) дээр хугацаа хэтэрсэн.

Өөрийн компьютер дээр санамсаргүй оролтод n = 2500 → 77 ms, 5000 → 300 ms, 10000 → 1233 ms
болж, n хоёр дахин өсөхөд хугацаа 4 дахин өсөв. Энэ хурдаар n = 5·10⁴ үед ойролцоогоор
30 секунд болно.

Дараа нь лабын 2-р даалгаврын нэгтгэн эрэмбэлэлтийг ашиглав. Нэг удаа нөөцлөсөн `buf`
массив руу хуулж буцааж нэгтгэх тул нэмэлт санах ой Θ(n), хугацаа Θ(n lg n). Өөрийн
компьютер дээр n = 5·10⁴ санамсаргүй оролтод 77 ms зарцуулсан.

## 2. Reverse Pairs (LeetCode 493)

- Холбоос: <https://leetcode.com/problems/reverse-pairs/>
- Бодолт: [lc493.py](lc493.py)

| Үр дүн | Runtime | Memory |
| ------ | ------: | -----: |
| Accepted (140/140) | 906 ms (44.1%-иас хурдан) | 37 MB |

**Аргачлал.** 5-р даалгаврын урвуу хос тоолох нэгтгэн эрэмбэлэлтийг өргөтгөв.
i < j, nums[i] > 2·nums[j] нөхцөлтэй хос нь (1) хоёулаа зүүн хагаст, (2) хоёулаа баруун
хагаст, эсвэл (3) i зүүн, j баруун хагаст байна. Эхний хоёрыг дахин дуудалтаар тоолно.
Гурав дахь төрлийг нэгтгэхээс өмнө тоолно: хоёр хагас эрэмбэлэгдсэн тул зүүн талын
i өсөхөд nums[i] > 2·nums[j] нөхцөлийг хангах баруун талын j-ийн тоо буурахгүй. Иймд
j заагч зөвхөн урагшилж, нэг түвшинд Θ(n) ажил хийнэ.

5-р даалгавраас ялгаатай нь тоолох нөхцөл (`>` 2·x) болон эрэмбэлэх нөхцөл (`<=`)
өөр учраас тоолох, нэгтгэх алхмыг тусад нь хийв. T(n) = 2T(n/2) + Θ(n) = Θ(n lg n).
Python-ы `int` халихгүй тул 2·nums[j] нь 2³¹-ээс давсан ч асуудалгүй (Java/C++ дээр
`long` хэрэгтэй).

## 3. Search in Rotated Sorted Array (LeetCode 33)

- Холбоос: <https://leetcode.com/problems/search-in-rotated-sorted-array/>
- Бодолт: [lc33.py](lc33.py)

| Үр дүн | Runtime | Memory |
| ------ | ------: | -----: |
| Accepted (197/197) | 0 ms (100%-иас хурдан) | 19.6 MB |

**Аргачлал.** 3-р даалгаврын Recursive-Binary-Search-ийг өөрчлөв. Хөрвүүлсэн жагсаалтыг
q цэгээр хуваахад хоёр хагасын ядаж нэг нь эрэмбэлэгдсэн байна:
nums[p] ≤ nums[q] бол зүүн тал, эс бөгөөс баруун тал. Эрэмбэлэгдсэн талын хоёр
захаар target тэр талд байгаа эсэхийг Θ(1)-д шалгаад, зөвхөн нэг тал руу дахин дуудна.
T(n) = T(n/2) + Θ(1) = Θ(lg n).
