## 1. Pow(x, n) (LeetCode 50)

- Холбоос: <https://leetcode.com/problems/powx-n/>
- Бодолт: [lc50.py](lc50.py)

| Үр дүн | Runtime | Memory |
| ------ | ------: | -----: |
| Accepted (309/309) | 0 ms (100%-иас хурдан) | 19.2 MB |

**Аргачлал.** xⁿ = (x^⌊n/2⌋)² бөгөөд n сондгой бол дээр нь x-ээр үржүүлнэ. Гол нь дэд бодлого
x^⌊n/2⌋-ийг **ганцхан удаа** бодож, үр дүнгээ өөрөөр нь үржүүлэх явдал. `power(k//2) * power(k//2)`
гэж хоёр удаа дуудвал T(n) = 2T(n/2) + Θ(1) = Θ(n) болж хэсэгчилсний ач холбогдол алдагдана.

T(n) = T(n/2) + Θ(1). Энэ нь 1-р даалгаврын R2 бөгөөд 2-р тохиолдлоор **Θ(lg n)**.
n = 2³¹ − 1 үед ердөө 31 түвшин (14 µs).

n сөрөг бол xⁿ = 1 / x^(−n). Java/C++-д n = −2³¹ үед −n нь int-ээс хальдаг тул `long` руу хөрвүүлэх
хэрэгтэй. Python-ы `int` хязгааргүй тул энэ асуудал гарахгүй.

## 2. Maximum Subarray (LeetCode 53)

- Холбоос: <https://leetcode.com/problems/maximum-subarray/>
- Бодолт: [lc53.py](lc53.py) — `SolutionDivideConquer`, `Solution` (шугаман)

| Хувилбар | Үр дүн | Runtime | Memory |
| -------- | ------ | ------: | -----: |
| Хэсэгчлэх | Accepted (210/210) | 853 ms | 46.9 MB |
| Шугаман | Accepted (210/210) | 38 ms | 31.3 MB |

**Хэсэгчлэх арга.** Хамгийн их нийлбэртэй дэд массив нь (1) бүхэлдээ зүүн хагаст, (2) бүхэлдээ
баруун хагаст, эсвэл (3) дунд цэгийг огтолж гарна. (1), (2)-ыг дахин дуудалтаар, (3)-ыг
mid-ээс зүүн тийш, mid+1-ээс баруун тийш хамгийн их угтвар нийлбэрээр Θ(n)-д олно.
T(n) = 2T(n/2) + Θ(n) = **Θ(n lg n)** (R1, нэгтгэн эрэмбэлэлттэй ижил).

**Шугаман арга (Kadane).** i-р гишүүнээр төгсөх хамгийн их нийлбэр нь `max(nums[i], өмнөх + nums[i])`.
Нэг удаа гүйгээд **Θ(n)** хугацаа, Θ(1) санах ой.

**Харьцуулалт.** LeetCode дээр хэсэгчлэх 853 ms, шугаман 38 ms (**22 дахин**). Өөрийн компьютер дээр
(санамсаргүй, n = 10⁵) 227 ms ба 9 ms (≈ 25 дахин). Хэсэгчлэх арга нэмэлт санах ой ч их (46.9 MB ба
31.3 MB) хэрэглэдэг, учир нь дахин дуудалтын стек болон түр хувьсагчид Θ(lg n) гүнтэй.
lg 10⁵ ≈ 17 түвшин болон Python-ы функцийн дуудалтын зардлаас ялгаа гарч байна.

## 3. Equivalent Strings (Codeforces 559B)

- Холбоос: <https://codeforces.com/problemset/problem/559/B>
- Бодолт: [cf559b.py](cf559b.py)

| Үр дүн | Хугацаа | Санах ой |
| ------ | ------: | -------: |
| Accepted (104/104, Python 3.13.2, [#396908324](https://codeforces.com/problemset/submission/559/396908324)) | 218 ms | 1 200 KB |

**Тодорхойлолтоор шууд бичвэл.** a, b тэнцүү биш, урт нь тэгш бол хагаслаад
(a₁≡b₁ ∧ a₂≡b₂) ∨ (a₁≡b₂ ∧ a₂≡b₁)-ийг шалгана. Хамгийн муу үед n/2 урттай **4** дэд бодлого:
T(n) = 4T(n/2) + Θ(n). n^(log₂4) = n² ≫ n тул 1-р тохиолдол, **Θ(n²)**. n = 2·10⁵ үед 4·10¹⁰ орчим
алхам болж хугацаанд багтахгүй.

**Сайжруулалт: каноник хэлбэр.** Мөр бүрд «хамгийн бага» эквивалент хэлбэрийг гаргана. Тэгш урттай
бол хагас бүрийн каноник хэлбэрийг гаргаад, лексикографын хувьд бага нь эхэнд орно. Хоёр мөр
эквивалент ⇔ каноник хэлбэрүүд нь тэнцүү. Одоо хагас бүрийг **нэг л удаа** дуудна:
T(n) = 2T(n/2) + Θ(n). 2-р тохиолдлоор **Θ(n lg n)**.

Шалгалт: 3000 санамсаргүй хосыг тодорхойлолтоор бичсэн хувилбартай харьцуулж таарсан.
