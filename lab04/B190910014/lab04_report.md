### 1. Ган саваа — `bottom_up_cut_rod`
`python/src/cut_rod.py`, `java/.../CutRod.java::bottomUp`. Лекцийн Bottom-Up-Cut-Rod:

```python
r = [0] * (n + 1)
for j in range(1, n + 1):
    q = -inf
    for i in range(1, j + 1):          # эхний хэсгийн урт
        q = max(q, p[i - 1] + r[j - i])
        loops += 1
    r[j] = q
```

**Хугацаа Θ(n²)** (давталт яг n(n+1)/2, доорх (г)), **санах ой Θ(n)** (r хүснэгт).

## Шинжилгээ

### (а) Ган савааны бодлого SRTBOT хэлбэрээр
| | |
| - | - |
| **S** — дэд бодлого | r(j): j урттай савааны хамгийн их орлого, j = 0, 1, …, n (n + 1 дэд бодлого) |
| **R** — хамаарал | r(j) = max₁≤ᵢ≤ⱼ ( pᵢ + r(j − i) ): эхний хэсгийн урт i-г бүх боломжоор сонгоно |
| **T** — топологи дараалал | j = 0, 1, …, n өсөх: r(j) нь зөвхөн бага j − i-ээс хамаарна |
| **B** — суурь нөхцөл | r(0) = 0 |
| **O** — үндсэн бодлого | r(n); огтлолтыг s[j]-ээр сэргээнэ |
| **T** — хугацаа | Σⱼ₌₁ⁿ Θ(j) = Θ(n²): n + 1 дэд бодлого, тус бүрд O(n) сонголт |

### (б) Оновчтой дэд бүтэц — «орлуулах» (cut-and-paste) баталгаа
n урттай савааны оновчтой шийдийн эхний хэсгийн урт i, орлого r(n) = pᵢ + R байг. Энд R нь
үлдсэн n − i урттай хэсгийн огтлолтоос олох орлого. **Үлдэгдлийн огтлолт оновчтой биш** гэж үзье:
тэгвэл n − i урттай савааг R′ > R орлоготой огтлох арга байна. Оновчтой шийдийн үлдэгдлийн
огтлолтыг «тайрч» энэ R′-тэй хувилбарыг «наавал» нийт орлого pᵢ + R′ > pᵢ + R = r(n) болж, r(n)
хамгийн их гэдэгт **зөрчил** үүснэ. Тиймээс R = r(n − i), өөрөөр хэлбэл оновчтой шийд нь
дэд бодлогын оновчтой шийдийг агуулна. Эндээс r(n) = maxᵢ (pᵢ + r(n − i)) томьёо гарна.

### (в) Дахин дуудах Cut-Rod-ийн дуудалт T(n) = 2ⁿ (математик индукц)
T(0) = 1, T(n) = 1 + Σⱼ₌₀^(n−1) T(j).
- **Суурь:** T(0) = 1 = 2⁰.
- **Алхам:** j < n бүрд T(j) = 2ʲ гэж үзье. Тэгвэл
  T(n) = 1 + Σⱼ₌₀^(n−1) 2ʲ = 1 + (2ⁿ − 1) = **2ⁿ** (геометр прогрессийн нийлбэр).

Иймд хүснэгтгүй Cut-Rod нь ижил r(j)-г экспоненциал олон удаа бодно. Доороос дээш арга дэд
бодлого бүрийг нэг удаа бодож Θ(n²) болгосон.

### (г) Дотоод давталт n(n+1)/2 удаа
j-р гадаад алхамд дотоод давталт i = 1, …, j буюу яг j удаа эргэнэ:
Σⱼ₌₁ⁿ j = n(n+1)/2 = Θ(n²). Функцийн тоолуураар (CLRS-ийн үнэ, p[1..n]):

### 5′. Diff: LCS хүснэгт → Myers-ийн алгоритм
`python/src/lcs_diff_myers.py`, `java/.../Lcs.java::diffMyers`.

**Санаа.** Засварын граф дээр (0, 0)-оос (N, M) хүрэх замд «баруун» = A-аас хасах, «доош» = B-д
нэмэх, «диагональ» = ижил мөр (үнэгүй). D = хасах + нэмэх алхмын хамгийн бага тоо. v[k] нь
d алхмаар k = x − y диагональ дээр хүрэх хамгийн хол x. d = 0, 1, 2, … гэж өсгөж, (N, M)-д хүрмэгц
зогсоно. Замаа сэргээхийн тулд d бүрийн v-г хадгална. D = N + M − 2·LCS тул нийтлэг мөрийн тоо
LCS-тэй ижил, хариу нь өмнөхтэй адил оновчтой. **git diff яг энэ алгоритмыг ашигладаг.**

| | Хүснэгтийн арга | Myers |
| - | - | - |
| Хугацаа | Θ(N·M) | O((N + M)·D) |
| Санах ой | Θ(N·M) | O(D²) |

### 4′. Матрицын цуваа: DP оновчтой → энгийн шийдэлтэй харьцуулах
Θ(n³) хүснэгтийн аргыг энэ лабын хүрээнд оновчтой гэж үзэв (Hu–Shing-ийн O(n lg n) алгоритм
байдаг ч хэт нарийн). Тиймээс PDF-ийн зааврын дагуу **илүү энгийн шийдэл**-ийг
(`python/src/matrix_chain_recursive.py`, `MatrixChain.recursive`) боловсруулж харьцуулав:
томьёог хүснэгтгүйгээр шууд дахин дуудах Recursive-Matrix-Chain.

Дуудалтын тоо C(1) = 1, C(n) = 1 + Σₖ₌₁^(n−1) (C(k) + C(n−k)) = 1 + 2·Σₖ₌₁^(n−1) C(k) тул
C(n) = 3·C(n−1) буюу **C(n) = 3ⁿ⁻¹** (тестээр шалгав). Харин өөр өөр дэд бодлого ердөө
n(n+1)/2. Хүснэгт ижил (i, j)-г дахин бодохоос сэргийлж экспоненциалыг Θ(n³) болгодог.

(Python ≈ 1 KB, Java ≈ 0), харин DP хоёр n × n хүснэгтэд Θ(n²) санах ой зарцуулна. Энэ бол хугацаа
ба санах ойн солилцоо: Θ(n²) санах ой «зарж» экспоненциал хугацааг Θ(n³) болгож байна.
