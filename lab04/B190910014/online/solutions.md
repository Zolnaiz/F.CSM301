## (C) Cut Ribbon (Codeforces 189A)

- Холбоос: <https://codeforces.com/problemset/problem/189/A>
- Бодолт: [cf189a.py](cf189a.py)

| Үр дүн | Хугацаа | Санах ой |
| ------ | ------: | -------: |
| Accepted (58/58, Python 3.13.2, [#396911341](https://codeforces.com/problemset/submission/189/396911341)) | 62 ms | ≈ 0 KB |

**Аргачлал.** Ган савааны бодлоготой ижил бүтэцтэй, зөвхөн a, b, c гэсэн гурван урттай хэсэг
зөвшөөрөгдөнө. Үнийн оронд **хэсгийн тоог** хамгийн их болгоно.
- Дэд бодлого: best[i] нь i урттай туузыг үлдэгдэлгүй хуваахад гарах хамгийн олон хэсэг.
- Хамаарал: best[i] = max(best[i − a], best[i − b], best[i − c]) + 1, хүрэх боломжгүйг −1-ээр тэмдэглэнэ.
- Суурь: best[0] = 0. Хариу: best[n].

i бүрд 3 сонголт тул **Θ(n)** хугацаа, **Θ(n)** санах ой.

## (B) Edit Distance (LeetCode 72)

- Холбоос: <https://leetcode.com/problems/edit-distance/>
- Бодолт: [lc72.py](lc72.py)

| Үр дүн | Runtime | Memory |
| ------ | ------: | -----: |
| Accepted (1149/1149) | 36 ms (80.7%-иас хурдан) | 19.1 MB (98.7%-иас бага) |

**Аргачлал.** LCS-тэй төстэй хоёр хэмжээст хүснэгт. dist[i][j] нь word1[:i]-г word2[:j] болгох
хамгийн цөөн засвар. Тэмдэгт ижил бол dist[i−1][j−1], эс бөгөөс
1 + min(солих dist[i−1][j−1], устгах dist[i−1][j], оруулах dist[i][j−1]).
Суурь: dist[i][0] = i, dist[0][j] = j. Хүснэгтийг мөр мөрөөр бөглөх тул хоёр мөр хадгална:
**Θ(mn)** хугацаа, **Θ(n)** санах ой. LeetCode-ийн санах ойн 98.7%-иас бага гарсан нь энэ хоёр
мөрийн аргын ач холбогдол.

## (A) Longest Increasing Subsequence (LeetCode 300)

- Холбоос: <https://leetcode.com/problems/longest-increasing-subsequence/>
- Бодолт: [lc300.py](lc300.py) — `SolutionQuadratic`, `Solution`

| Хувилбар | Үр дүн | Runtime | Memory |
| -------- | ------ | ------: | -----: |
| Θ(n²) | Accepted (57/57) | 1052 ms | 19.3 MB |
| Θ(n lg n), хоёртын хайлт | Accepted (57/57) | **10 ms** | 19.5 MB |

**1-р хувилбар, Θ(n²).** lis[i] нь nums[i]-ээр төгсөх хамгийн урт өсөх дэд дараалал:
lis[i] = 1 + max{lis[j] : j < i, nums[j] < nums[i]}. i бүрд өмнөх бүх j-г шалгана.

**2-р хувилбар, Θ(n lg n).** tails[L] нь L+1 урттай өсөх дэд дарааллын **хамгийн бага сүүл**.
Сүүл бага байх тусам дараа нь өргөтгөх боломж ихтэй. tails үргэлж өсөх эрэмбэтэй байдаг тул x бүрд
x ≤ tails[k] байх хамгийн бага k-г **хоёртын хайлтаар** (өөрсдөө бичсэн, `bisect`-гүй) олж
tails[k] = x болгоно. Ийм k байхгүй бол төгсгөлд нэмнэ. Хариу нь len(tails).

**Харьцуулалт.** LeetCode дээр 1052 ms → 10 ms (**105 дахин**), өөрийн компьютер дээр
n = 2500 үед 205 ms → 1.3 ms (≈ 160 дахин). Санах ой хоёуланд нь Θ(n).
