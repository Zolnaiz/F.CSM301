**Хомхойлох арга.** 1–4 хүнтэй бүлгүүдийг тоолно (c₁…c₄). 4-ийн бүлэг бүр тусдаа такси. 3-ын

## 3. Task Scheduler (LeetCode 621) — A

- Холбоос: <https://leetcode.com/problems/task-scheduler/>
- Бодолт: [lc621.py](lc621.py)

| Үр дүн | Runtime | Memory |
| ------ | ------: | -----: |
| Accepted (72/72) | 16 ms (87.50%-иас хурдан) | 20.40 MB (99.61%-иас бага) |

**Томьёо.** Хамгийн олон давтагдсан ажлын тоо f, ийм ажлын төрлийн тоо c бол

  хариу = max(N, (f − 1)·(n + 1) + c).

Хамгийн олон давтагдсан ажлуудыг (n + 1) урттай f − 1 «хүрээ» болгон тавьж, сүүлийн хүрээнд c
ажил үлдээнэ. Бусад ажлыг хоосон зайнд хомхойлон дүүргэнэ. Зай хүрэхгүй бол хоосон зай огт
хэрэггүй тул хариу N. Доод хязгаар: f удаа давтагдах ажлын хооронд n-ээс доошгүй зай байх тул
(f − 1)(n + 1) + c-ээс бага байж чадахгүй. Хугацаа Θ(N), санах ой Θ(1) (26 үсэг).

**Шалгалт.** Алхам бүрд үлдсэн тоо нь хамгийн их, хүлээх шаардлагагүй ажлыг сонгох хомхойлох
симуляц (`SolutionSimulation`, heap + дараалал)-тай 300 санамсаргүй оролтод таарсан. Симуляц нь
O(хариу · lg 26), томьёо нь хариунаас үл хамааран Θ(N).
