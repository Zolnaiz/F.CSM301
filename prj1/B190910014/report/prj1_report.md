### 1.2 Хэсэгчлэх арга ба дахин дуудах тэгшитгэл
Хэсэгчлэх арга гурван алхамтай: **хуваах** (ижил төрлийн жижиг дэд бодлогууд), **бодох** (дэд
бодлогыг дахин дуудалтаар; хангалттай жижиг бол шууд), **нэгтгэх** (дэд шийдүүдээс эх бодлогын
шийд). n хэмжээтэй бодлогыг n/b хэмжээтэй a дэд бодлогод хувааж, хуваах ба нэгтгэхэд f(n) ажил
зарцуулбал

  T(n) = a·T(n/b) + f(n).

Ерөнхий теоремоор (лекцийн Теорем 5.1–5.2) f(n)-г n^(log_b a) урсгал функцтэй харьцуулна:
(1) f = O(n^(log_b a − ϵ)) → Θ(n^(log_b a)); (2) f = Θ(n^(log_b a) lg^k n), k ≥ 0 →
Θ(n^(log_b a) lg^(k+1) n); (3) f = Ω(n^(log_b a + ϵ)) ба a·f(n/b) ≤ c·f(n), c < 1 → Θ(f(n)).
Тэгш биш хуваалттай (жишээ нь 5-р бодлого) тэгшитгэлийг давталтын мод эсвэл орлуулгаар бодно.

## 2. Бодлого 1. Majority Element (LeetCode 169)

### 2.1 Зорилго
n урттай массиваас ⌊n/2⌋-аас олон удаа орсон (олонх) гишүүнийг олно. Ийм гишүүн заавал байна.

### 2.2 Алгоритмын санаа
**Ажиглалт:** m нь бүх массивын олонх гишүүн бол зүүн эсвэл баруун хагасын **ядаж нэгд нь**
олонх байна. Хэрэв хоёр хагаст хоёуланд нь хагасаас олон биш байсан бол нийт тоо нь
n/2-оос хэтрэхгүй. Тиймээс:
1. **Хуваах:** [lo, hi)-г дундуур нь хоёр хуваана.
2. **Бодох:** хагас бүрийн олонх гишүүнийг дахин дуудалтаар олно (суурь: ганц гишүүн).
3. **Нэгтгэх:** хоёр нэр дэвшигч ижил бол тэр. Өөр бол [lo, hi)-д хоёуланг тоолж, олон удаа
   орсныг сонгоно.

```python
def majority(lo, hi):                 # nums[lo:hi]-ийн олонх гишүүн
    if hi - lo == 1:
        return nums[lo]
    mid = (lo + hi) // 2
    left, right = majority(lo, mid), majority(mid, hi)
    if left == right:
        return left
    left_count = sum(1 for i in range(lo, hi) if nums[i] == left)
    right_count = sum(1 for i in range(lo, hi) if nums[i] == right)
    return left if left_count > right_count else right
```

### 2.3 Хугацаа
Хамгийн муу үед түвшин бүрт тоолох ажил Θ(n):
**T(n) = 2T(n/2) + Θ(n)** → a = b = 2, n^(log₂2) = n = f(n), 2-р тохиолдол (k = 0) →
**Θ(n lg n)**. Хамгийн сайн үед (бүх гишүүн ижил) нэгтгэх алхам Θ(1) тул
T(n) = 2T(n/2) + Θ(1) = Θ(n).

### 2.4 Санах ой
Массивыг хуулахгүй, зөвхөн (lo, hi) товъёгоор дамжуулна. Нэмэлт санах ой нь дахин дуудалтын
стекийн гүн ⌈lg n⌉ буюу **Θ(lg n)**. Хэмжилтэд Python-ы оргил хэдхэн KB, Java-д хуваарилалт 0
байгаа нь (стек тоологдохгүй) үүнийг харуулна.

Харьцуулахад Boyer–Moore-ийн санал хураах арга нэг удаа гүйгээд **Θ(n)** хугацаа, **Θ(1)** санах
ойтой. Хэсэгчлэх арга lg n дахин удаан ч бодлогыг хувааж, нэгтгэх санааг тодорхой харуулдаг.

## 3. Бодлого 2. Convert Sorted Array to Binary Search Tree (LeetCode 108)

### 3.1 Зорилго
Өсөхөөр эрэмбэлэгдсэн массиваас **өндрөөр тэнцвэртэй** хоёртын хайлтын мод байгуулна.

### 3.2 Алгоритмын санаа
Дунд гишүүнийг үндэс болговол зүүн тал нь бүгд бага, баруун тал нь бүгд их (хайлтын модны нөхцөл),
хоёр талын хэмжээ хамгийн ихдээ 1-ээр ялгаатай (тэнцвэр). Хоёр талыг дахин дуудалтаар байгуулна.

```python
def build(lo, hi):                    # nums[lo..hi]
    if lo > hi:
        return None
    mid = (lo + hi) // 2
    return TreeNode(nums[mid], build(lo, mid - 1), build(mid + 1, hi))
```

Модны өндөр яг ⌈lg(n+1)⌉ бөгөөд энэ нь n зангилаатай хоёртын модны хамгийн бага өндөр (тестээр
шалгав).

үүсгэдэг тул Ω(n)-ээс бага байж чадахгүй.

## 4. Бодлого 3. Longest Nice Substring (LeetCode 1763)

### 4.1 Зорилго
Үсэг бүр нь том, жижиг хоёр хэлбэрээрээ орсон мөрийг «сайхан» гэнэ. Хамгийн урт сайхан дэд мөрийг
олно. Ижил урттай хэд байвал хамгийн эхнийхийг буцаана.

### 4.2 Алгоритмын санаа
**«Муу» үсэг:** эсрэг хэлбэр нь s-д огт байхгүй үсэг. Муу үсэг агуулсан дэд мөр хэзээ ч сайхан
болохгүй. Тиймээс:
1. **Хуваах:** s-ийг бүх муу үсгээр нь нэг дор хэсэглэнэ.
2. **Бодох:** хэсэг бүрийг дахин дуудалтаар бодно.
3. **Нэгтгэх:** хамгийн урт хариуг авна (тэнцүү бол эхнийх).

Муу үсэг байхгүй бол s өөрөө сайхан.

```python
def longestNiceSubstring(s):
    if len(s) < 2:
        return ""
    present = set(s)
    best, start, split = "", 0, False
    for i, ch in enumerate(s):
        if ch.swapcase() not in present:          # муу үсэг
            split = True
            part = longestNiceSubstring(s[start:i])
            if len(part) > len(best):
                best = part
            start = i + 1
    if not split:
        return s
    part = longestNiceSubstring(s[start:])
    return part if len(part) > len(best) else best
```

### 4.3 Хугацаа
Хэсгүүдийн нийт урт < n тул түвшин бүрийн нийт ажил Θ(n):
T(n) = Σ T(nᵢ) + Θ(n), Σ nᵢ < n. **Гүний хязгаар:** нэг түвшинд хуваасан муу үсгийн төрөл
хүүхдийн бүх хэсгээс бүрмөсөн алга болно. Тиймээс түвшин бүрт хэсэгт байгаа үсгийн төрлийн тоо
дор хаяж 1-ээр буурч, гүн ≤ |Σ| = 52 болно. Нийт **Θ(|Σ|·n) = Θ(n)** (|Σ| тогтмол).

Хэрэв зөвхөн эхний муу үсгээр хуваавал «aaaa…a» мэт оролтод гүн n болж Θ(n²) болно. Бүх муу
үсгээр нэг дор хуваах нь энэ муу тохиолдлоос сэргийлдэг.

### 4.4 Санах ой
`present` олонлог Θ(|Σ|). Python хувилбар дэд мөрийг хуулдаг тул нэг түвшинд Θ(n) түр санах ой,
стекийн гүн ≤ 52. Java хувилбар хуулалгүй (lo, hi) товъёгоор дамжуулж, дуудалт бүрд `boolean[128]`
хэрэглэдэг. Тиймээс **нэгэн зэрэг амьд** байх нэмэлт санах ой нь Θ(|Σ|·гүн) = **Θ(1)** (гаралтын
мөрөөс бусдаар). Python-ы оргил утга n-ээс үл хамааран ≈ 1–5 KB байгаа нь үүнийг харуулж байна.

Java-ийн хүснэгтэд «split» үед санах ой n-тэй хамт өсөж байгаа нь **нийт хуваарилалт** юм. Дуудалт
бүр шинэ `boolean[128]` (≈ 144 байт) үүсгэх бөгөөд «z» үсэг 11 тэмдэгт тутамд нэг таарч, дуудалтын
тоо ≈ n/11 болно: n = 10⁵ үед ≈ 9 000 дуудалт × 144 байт + бусад ≈ 2.9 MB. Эдгээр массив дуудалт
дуусмагц хог болдог тул оргил санах ойд нөлөөлөхгүй. «Нийт хуваарилалт» ба «оргил санах ой» гэдэг
хоёр өөр хэмжигдэхүүнийг ялгах нь чухал.

## 5. Бодлого 4. Different Ways to Add Parentheses (LeetCode 241)

### 5.1 Зорилго
`+`, `-`, `*` үйлдэл ба тоо агуулсан илэрхийлэлд хаалтыг бүх боломжит аргаар тавьж гарах бүх утгыг
буцаана.

### 5.2 Алгоритмын санаа (B түвшин)
Хамгийн сүүлд хийгдэх үйлдлийг сонгоод илэрхийллийг хоёр хуваана. Зүүн, баруун талын бүх утгыг
дахин дуудалтаар олоод, хос бүрт тэр үйлдлийг хэрэглэнэ.

```python
def diffWaysToCompute(expression):
    results = []
    for i, ch in enumerate(expression):
        if ch in "+-*":
            left = diffWaysToCompute(expression[:i])
            right = diffWaysToCompute(expression[i + 1:])
            for x in left:
                for y in right:
                    results.append(apply(x, y, ch))
    if not results:                       # үйлдэлгүй — ганц тоо
        results.append(int(expression))
    return results
```

### 5.3 Хугацаа ба санах ой (B түвшин)
k үйлдэлтэй илэрхийлэлд хариуны тоо нь **Каталаны тоо** Cₖ = (2k)! / ((k+1)!·k!) ≈ 4ᵏ / (k^1.5·√π).
Гаралт өөрөө ийм хэмжээтэй тул аль ч алгоритм Ω(Cₖ).

Дуудалтын тоо: C(0) = 1, C(k) = 1 + Σⱼ₌₀^(k−1) [C(j) + C(k−1−j)] = 1 + 2·Σⱼ₌₀^(k−1) C(j) тул
C(k) = 3·C(k−1) буюу **C(k) = 3ᵏ** (тестээр шалгав). Гэтэл өөр өөр дэд илэрхийлэл ердөө
(k+1)(k+2)/2 л бий. Тэгэхээр **ижил дэд бодлогыг олон дахин** бодож, дэд мөрийг хуулж, тоог дахин
задалж байна. Түр жагсаалтуудын нийт хэмжээ ч гурвын зэргээр өснө.

### 5.4 Сайжруулсан шийдэл (A түвшин)
1. Илэрхийллийг **нэг удаа** тоо, үйлдлийн жагсаалт болгон задална (дэд мөр хуулахгүй).
2. Дэд бодлогыг операндын **товъёгийн муж (i, j)**-ээр тодорхойлж, хариуг **санана (memo)**.

```python
def compute(i, j):                        # nums[i..j] операндууд
    if (i, j) in memo:
        return memo[(i, j)]
    if i == j:
        result = [nums[i]]
    else:
        result = [apply(x, y, ops[k])
                  for k in range(i, j)
                  for x in compute(i, k)
                  for y in compute(k + 1, j)]
    memo[(i, j)] = result
    return result
```

Дэд бодлого бүр яг нэг удаа бодогдоно: **(k+1)(k+2)/2** удаа. Хугацаа нь бүх дэд бодлогын хариуг
байгуулах ажилтай тэнцүү, ойролцоогоор Θ(Σ_m (k+1−m)·C_m) = Θ(Cₖ). Энэ нь гаралтын хэмжээтэй ижил
эрэмбэтэй тул асимптот оновчтой.

## 6. Бодлого 5. Construct Binary Tree from Preorder and Inorder Traversal (LeetCode 105)

### 6.1 Зорилго
Ялгаатай утгатай хоёртын модны preorder ба inorder тойрлоос модыг сэргээнэ.

### 6.2 Алгоритмын санаа (B түвшин)
preorder[0] нь үндэс. inorder-т үндсээс зүүн талд зүүн дэд мод, баруун талд баруун дэд мод
байрлана. Хэрэв үндэс inorder-ийн k байрлалд байвал preorder[1..k] нь зүүн дэд модны preorder.
Хоёр жагсаалтыг хуваагаад хоёр дэд модыг дахин дуудалтаар сэргээнэ.

```python
def buildTree(preorder, inorder):
    if not preorder:
        return None
    root = TreeNode(preorder[0])
    k = inorder.index(preorder[0])                    # Θ(n) хайлт
    root.left = buildTree(preorder[1:k + 1], inorder[:k])
    root.right = buildTree(preorder[k + 1:], inorder[k + 1:])
    return root
```

### 6.3 Хугацаа ба санах ой (B түвшин)
Дуудалт бүр шугаман хайлт ба хуулалтад Θ(n) зарцуулна: T(n) = T(k) + T(n−1−k) + Θ(n).
- **Тэнцвэртэй ойролцоо мод** (k ≈ n/2): T(n) = 2T(n/2) + Θ(n) = **Θ(n lg n)** (R1).
- **Нэг талдаа тулсан мод** (k = n−1 буюу гинж): T(n) = T(n−1) + Θ(n) = Σ Θ(i) = **Θ(n²)**.

Санах ой: зүсмэл бүр шинэ жагсаалт. Гинжин модонд дахин дуудалтын зам дээрх бүх зүсмэл зэрэг амьд
байх тул оргил санах ой n + (n−1) + … ≈ n²/2 буюу **Θ(n²)** болно.

### 6.4 Сайжруулсан шийдэл (A түвшин)
1. inorder-ийн **утга → товъёг**-ийг хэш хүснэгтэд нэг удаа хадгална: хайлт **Θ(1)**.
2. Жагсаалт хуулахгүй, inorder-ийн (lo, hi) мужаар дамжуулна. preorder-ийг нэг заагчаар дарааллаар
   уншина, учир нь preorder-т үндэс → зүүн дэд мод → баруун дэд мод гэсэн дараалалтай.

```python
position = {value: i for i, value in enumerate(inorder)}
next_root = 0

def build(lo, hi):                                    # inorder[lo..hi]
    nonlocal next_root
    if lo > hi:
        return None
    value = preorder[next_root]; next_root += 1
    k = position[value]                               # Θ(1)
    root = TreeNode(value)
    root.left = build(lo, k - 1)
    root.right = build(k + 1, hi)
    return root
```

Одоо T(n) = T(k) + T(n−1−k) + Θ(1) тул модны хэлбэрээс үл хамааран **Θ(n)**. Санах ой: хэш
хүснэгт Θ(n) + стек Θ(h), h ≤ n.

**Гол дүгнэлтүүд:**

1. **Хэсэгчлэх аргын өртөг нь хуваах, нэгтгэх алхмын өртгөөс шууд хамаарна.** 1, 2-р бодлого

2. **Дэд бодлого давхцаж байвал санах (memo).** 4-р бодлогод ижил дэд илэрхийллийг 3ᵏ удаа бодож
   байсныг (k+1)(k+2)/2 болгов. Энэ нь динамик программчлалын санаа бөгөөд Лаб 4-ийн сэдэв.
3. **Хуулалт ба шугаман хайлтыг товъёг, хэш хүснэгтээр солих.** 5-р бодлогод хамгийн муу тохиолдлын
   Θ(n²)-ийг Θ(n) болгосон. Санамсаргүй өгөгдөл дээр ялгаа бага ч хамгийн муу оролтод хэдэн
   арав дахин.
4. **Хуваах стратеги хамгийн муу тохиолдлыг тодорхойлно.** 3-р бодлогод бүх муу үсгээр нэг дор
   хуваах нь гүнийг ≤ 52 болгож, Θ(n²) болох муу тохиолдлоос сэргийлсэн.
5. **Python, Java хоёрын үр дүнгийн хандлага ижил, тогтмол үржүүлэгч өөр.** Java 15–160 дахин
   хурдан байсан ч (P4: 14×, P1: 89×, P2: 160×) n-ээр өсөх хурд хоёр хэлэнд ижил байв. Санах ойн хэмжилтэд
   «оргил» ба «нийт хуваарилалт» гэсэн хоёр өөр хэмжигдэхүүнийг ялгаж тайлбарлах хэрэгтэй.
